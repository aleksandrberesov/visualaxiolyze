# Требования к виртуальной машине (ВМ) для запуска Visual Axiolyze

Приложение — это веб-приложение на Python (Reflex) с бэкендом GLM-моделирования.
Внешние сервисы не нужны: база данных встроенная (SQLite), авторизация локальная,
GPU не требуется.

Размер ВМ определяется двумя «тяжёлыми» частями:

- **Сборка фронтенда Reflex** — под капотом компилируется фронтенд на Next.js через
  Node.js, этот шаг требователен к оперативной памяти.
- **Научный стек Python** — numpy, scipy, pandas, scikit-learn, statsmodels, plotly,
  matplotlib, jupyter, **ydata-profiling** — занимает много места на диске и в памяти.

---

## Характеристики ВМ

| Ресурс | Минимум | Рекомендуется |
|---|---|---|
| **ОС** | Ubuntu 22.04 / Debian 12 (64-бит) или Windows 10/11 / Server 2022 | Ubuntu 22.04 LTS |
| **CPU** | 2 vCPU | 4 vCPU |
| **RAM** | 4 ГБ (+2 ГБ swap — при 4 ГБ сборка фронтенда может упасть по нехватке памяти) | 8 ГБ |
| **Диск** | 15 ГБ свободно | 25–30 ГБ (SSD) |
| **Сеть** | исходящий интернет для установки; входящие порты **3322** и **8000** | то же |

### Почему такие цифры

- **RAM** — при первом запуске Reflex компилирует фронтенд на Next.js через Node.js,
  что само по себе требует ~1,5–2 ГБ. Загрузка Python-стека добавляет ещё. Плюс сами
  данные лежат в памяти pandas: закладывайте примерно **5–10× от размера
  CSV/Parquet-файла** в RAM во время преобразований, так как трансформеры копируют
  таблицы. 4 ГБ хватит для небольших тестовых датасетов; 8 ГБ — комфортно.
- **Диск** — полное виртуальное окружение (scipy, statsmodels, ydata-profiling, jupyter,
  plotly, matplotlib и т. д.) занимает ~3–4 ГБ, Node + `node_modules` + сборка `.web` —
  ещё ~1 ГБ, сама ОС ~5 ГБ. Добавьте ещё ~2–3 ГБ, если запускаете через Docker (образ).
- **Интернет при установке** — обязателен. Reflex при первом `reflex run`/`export`
  скачивает инструментарий фронтенда (зависимости Bun/Node), а `pip` тянет пакеты.
  После первой успешной сборки приложение может работать офлайн.

## Два способа установки на ВМ

### A. Docker внутри ВМ (самый простой)

- На **Linux**-ВМ достаточно обычного Docker Engine — **вложенная виртуализация
  не нужна**, потому что Linux-контейнеры используют ядро самой ВМ.
- Единственный случай, когда нужна вложенная виртуализация / включённый Hyper-V, —
  это **Windows**-ВМ с Docker Desktop (бэкенд WSL2). Такой связки лучше избегать —
  используйте Linux-ВМ для Docker.
- Запуск:
  ```bash
  docker compose up --build
  ```
  Затем откройте `http://<ip-вм>:3322`.

### B. Нативная установка внутри ВМ (без Docker)

- Требуются установленные на ВМ **Python 3.11** и **Node.js 20** (Node обязателен —
  Reflex использует его, хотя весь код на Python).
- Далее — по инструкции из `CLAUDE.md`:
  ```bash
  git submodule update --init --recursive
  python -m venv .dev
  source .dev/bin/activate            # Linux/macOS
  # .dev\Scripts\Activate             # Windows
  pip install -e ./deps/repo_vdag
  pip install -e ./deps/repo_glm

  # Первый запуск — инициализация БД авторизации:
  cd deps/repo_vdag
  reflex db init
  cd ../..

  # Запуск приложения:
  python bridge_layer/main.py
  ```

## Доступ и порты

Откройте порты **3322** (веб-интерфейс) и **8000** (websocket бэкенда) в файрволе ВМ /
группе безопасности облака, если планируете обращаться к приложению с другой машины,
и заходите на `http://<ip-вм>:3322`.

Либо оставьте порты закрытыми и используйте SSH-туннель:

```bash
ssh -L 3322:localhost:3322 -L 8000:localhost:8000 user@<ip-вм>
```

## Итог

- **Нижняя планка:** Linux-ВМ 2 vCPU / 4 ГБ RAM / 15 ГБ диска.
- **Комфортный вариант:** Ubuntu, 4 vCPU / 8 ГБ RAM / 25 ГБ диска.
- GPU не нужен, внешняя БД не нужна, вложенная виртуализация не нужна
  (кроме варианта Docker Desktop на Windows — его лучше не использовать).
